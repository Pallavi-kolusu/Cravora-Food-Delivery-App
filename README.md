
# 🍔 Cravora – Food Delivery Web Application

Cravora is a Java Full Stack web application developed to provide a convenient food ordering experience. Users can explore restaurants, browse menus, manage their cart, and place food orders.

## ✨ Key Features
- User registration and login
- Restaurant listing and menu browsing
- Add to cart and cart management
- Checkout and order placement
- Order history and order confirmation
- User profile management

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript, JSP
- **Backend:** Java, Servlets, JDBC
- **Database:** MySQL
- **Tools:** Eclipse IDE, Apache Tomcat, MySQL Workbench, Git, GitHub

## 🏗️ Architecture

The application uses Java Servlets to handle requests, DAO classes to manage database operations, JSP pages to display the user interface, and MySQL to store application data.

## 🚀 How to Run

1. Clone or download this repository.
2. Import the project into Eclipse.
3. Configure Apache Tomcat.
4. Create the required MySQL database and tables.
5. Configure the database connection in your local environment.
6. Run the application on the Tomcat server.

## 🔐 Security

Configure database credentials locally. Do not publish passwords, API keys, or private information.
